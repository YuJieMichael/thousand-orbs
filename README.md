# 千珠落尽 · Thousand Orbs

一款在浏览器里玩的弹珠开包游戏：瞄准、发射宝珠，让它在铆钉和卡包之间弹跳，撞破封印开出卡牌，用卡牌技能组合出自己的流派。

## 怎么玩

在线试玩：<https://yujiemichael.github.io/thousand-orbs/>

也可以直接用浏览器打开 `index.html`，不需要安装任何东西。进度保存在浏览器本地，可以在「更多 → 设置」里导出存档码，换设备时再导入。游戏自动保留上一份有效备份；读取异常时会提供恢复或导入入口，保存失败时会提示导出和重试。

## 主要内容

- **5 个流派、37 张卡牌**：连击、灼烧、腐蚀、财富、引力，同流派装备越多共鸣越强。
- **6 张秘卡**：卡包里开不出来，要先按图鉴里的谜语触发彩蛋解锁。
- **星盘**：像 POE 一样从中心向外点亮的天赋树，五个方向尽头各有一块有代价的基石。
- **连锁倍率**：宝珠每撞一下倍率就涨一点，撞金钉、爆钉、分裂钉有额外效果；落底时按底部口袋（×1 / ×2 / ×5）兑现一路攒下的珠金；连撞够多进入狂热。
- **每轮目标**：开够指定数量的卡包才算数，连胜越长奖励越多，没达成就断连胜。
- **路线与珠袋**（打过第一个首领后开放）：每轮结束后选下一轮去普通、精英、黑市还是奇遇；宝珠分火珠、重珠、裂珠等类型，能看到接下来的三颗。特殊宝珠在精英轮达成后和奇遇中获得。
- **手机构筑**：两列卡牌显示完整效果，点卡牌装备或卸下，点「详情」查看当前构筑加成；换装后停在原位置。
- **逐步教学**：开场先教发射和开包，首次有足够金币时引导打磨宝珠，倍率与共鸣在遇到时提示。完整规则在「更多 → 设置 → 玩法说明」。
- **五章首领**：每个首领有专属技能，半血进入第二阶段（有特写镜头）并追加技能；之后是无尽深渊。
- **首领成长与奖励**：血量参考章节基础和前三章首次挑战时的单发伤害，不受普通轮群伤或过量伤害抬升。同章重试保持血量，升级和换装可提高通关能力；整体血量最多为上一章首领的 12 倍（首章或缺少记录时，以该章基础血量的 12 倍封顶）。击败首领正常结算金币与卡牌。
- **排行榜**（「目标 → 排行榜」）：最远进度、单轮金币、最长连胜、单珠连锁四个榜；起个昵称就能上榜，每轮结算自动上传刷新的成绩。
- **局内三选一祝福、挑战关卡、熔金转生**。

## 排行榜后端

- Worker `thousand-orbs-board`：<https://thousand-orbs-board.achat-vente-garderie.workers.dev>
- 数据库：D1 `thousand-orbs-board`，表结构在 `leaderboard/schema.sql`
- 接口：`GET /top?board=progress|coins|streak|chain&limit=50&pid=…`，`POST /submit`
- 部署是手动的，在 `leaderboard/` 文件夹里运行 `npx wrangler@4.151.1 deploy`（改表时先跑 `npx wrangler@4.151.1 d1 execute thousand-orbs-board --remote --file schema.sql`）
- 游戏在浏览器里跑，成绩没法真正防作弊；后端只做格式、范围检查和按 IP 限流（每分钟 60 次）。如果有人刷榜，可以直接在 D1 里删那一行

## 玩家统计

- 每轮结算时游戏匿名上传一条记录（随机玩家 id、轮次类型、章节、是否达成 / 击败、开包数、金币、时长、装备的卡、是否手机），存在 D1 的 `rounds` 表；玩家可以在「更多 → 设置」里关掉
- 统计页：<https://thousand-orbs-board.achat-vente-garderie.workers.dev/admin>，输入统计密码后看流派人气、最常用的卡、每人玩到第几章、各章首领胜率和目标达成率、挑战关卡、手机玩家占比、每天玩家数
- 统计密码是 Worker 的 secret `STATS_KEY`，本机副本在 `leaderboard/.stats-key`（不进 git）。换密码：`npx wrangler@4.151.1 secret put STATS_KEY`

## 2026-11-05.10：秘藏等级用血量换数量
- 秘藏等级让卡包血量变成 ×1.6^等级，所以开一个卡包也算 round(1.6^等级) 包：1 级算 2 包，3 级算 4 包，5 级算 10 包。这样目标不会因为升了等级反而完不成。
- 局内的目标文字和秘藏等级的说明里都会写「每个算 N 包」。
- 祝福出现的节奏和开包太多后的金币递减，仍然按真实开了几个卡包计算（`G.realOpened`）。每日挑战不受影响，固定算 1。
- 统计里的 opened 从这一版开始是折算后的包数。
