# 平衡检查：千珠落尽 经济系统（economy-designer · balance-check）

**数据来源**：`index.html`（常量和公式）、`README.md`（各版改动和统计依据）、`tests/*.cjs`（48/48 通过）。另外用 Playwright 模拟器在副本上跑了约 7 分钟（固定随机种子，「全部打出去」策略），脚本和原始输出在 `review/economy/`（sim2.cjs、routes_*.txt、ratchet_*.txt、odds.cjs）。

**健康结论：CONCERNS（有问题，调数值能解决）**。没发现没有出口的无限循环。精英和深挖属于「几乎不值得选」的选项，但不至于让某一种玩法压倒所有其他玩法。

**NOT ASSESSED（缺少数据）**：项目没有 GDD 或 registry 给出目标范围，下面只能拿 README 里写的设计意图来对照。线上统计看不到。新号第 1～2 章的曲线、首领要打多久、深渊和转生时机都没有模拟。

## 主要发现
1. **卡包血量倍率基本不起作用**。宝珠打磨每级伤害 ×1.4，价格每级 ×1.5，伤害很快远超卡包血量：中期伤害 Lv12 时，基础伤害 57，青铜包血量只有 8。模拟中期 6 个种子：精英轮卡包血量 ×2.2，开包数是普通轮的 1.10 倍，等于没变；深挖第 3 层（血量 ×2.2）是 0.96 倍。后期精英开包数 0.87 倍。所以真正决定难度的只有目标包数。
2. **精英轮**：目标 ×1.4。在已经追上实力的目标下，第 4～10 轮只有 3/21（14%）能达成，普通轮是 14/21（67%）。失败要掉一颗 ❤️，所以精英的期望收益是负的。
3. **深挖**：第 L 层目标是本章目标 ×(0.8+0.25(L−1))。第 1 层 0.8 倍目标，几乎稳赢，金币 1.43 倍，也不涨本章卡包强度，算白送。第 3 层要 1.3 倍目标，成功率估计约 15%，失败时连同背包一起丢（背包约等于 2.9 轮金币）。金魂从第 3 层才开始给，所以往深处挖几乎永远亏。
4. **目标跟得太紧**。一轮开包数波动很大（变异系数约 0.30）。达成后，下一轮目标会补上超出部分的 80%；差一点没达成时目标只降 2。目标追上实力以后，达成率只有约 67%，30 轮里出现了 1 次「本局结束」。把补差比例改成 0.6、没达成时降到开包数 ×0.95 再测：12/21，没有改善（样本少）。问题在于目标对单轮的运气反应太大，单调这两个系数没用。
5. **转生目标没有换算**。目标包数里含有秘藏等级的「一包算几包」（最多 10）和清点术倍率，转生会把这两项清零，但目标照样保留 30%。例子：目标 900、计数倍率 ×14.8，转生后要在第 1 章真开 270 包，而实力大约只有 45～60 包。头两轮必掉两颗 ❤️。
6. **收入膨胀**：不升级时，本章卡包强度带来每轮金币 +15%，第 10 轮约为开始的 3.5 倍，但开包数没有下降。每轮都买最便宜的升级时，同一章里每轮收入约 ×1.7（第 10 轮 4.5 万～24.5 万）。下一级的价格同期约为 9 万～13 万，消耗跟得上。秘藏等级价格每级 ×3.4，金币每级只 ×2，会自己卡住，不会失控。
7. **稀有度和保底**：第 1 章、秘藏等级 0 时，SSR 平均 121 包出 1 张，100 张保底的触发率 44%。秘藏等级 5 加慧眼点满后，SSR 变成 7.9%/包；秘藏等级 15 时 18.8%。秘藏等级上限是最远章节 ×3，深渊里没有尽头，黑金秘藏出现率（0.2%+0.2%×等级）也跟着无限涨。第 3 章以后保底几乎不会触发（0.2%），星盘上的「黑金之约」后期没用。另外 `PITY=40` 是没被使用的废常量。
8. **首领能压血**：第 1～3 章首领血量 ≥ 首次挑战时的单发伤害 ×26/34/42，然后锁定。第一次故意带弱配装去打，只花一颗 ❤️，就能锁住低血量。

## 优先级建议
| 级别 | 常量 / 公式 | 改动 | 原因 |
|---|---|---|---|
| P1 | `ELITE_GOAL` | 1.4 → **1.1** | 达成率 14% → 预计 50% 左右；血量 ×2.2 保留 |
| P1 | `DELVE_GOAL_STEP` | 0.25 → **0.10**（各层 0.8/0.9/1.0/1.1） | 让第 2～3 层成为真正需要权衡的冒险 |
| P1 | `prestige()` 里的目标 | 改为 `max(8, round(goal×0.3 ÷ (packWorth×cntMult)))`，在清零升级之前算 | 避免转生后必掉 ❤️ |
| P1 | 目标公式 | 新增 `GOAL_EMA=.5`，目标 = round(**0.8**×开包数的滑动平均)；达成后单轮最多 +50%，只有开包数 ≥ 2 倍目标时才允许翻倍 | 达成率目标约 75～80%，老玩家仍然能很快追上 |
| P2 | `packValue` 里的本章强度倍率 | 金币改用 **1.07**^本章已打轮数，血量保持 1.15 | 打的轮数越多金币越多，难度却没变 |
| P2 | 宝珠打磨价格 | 每级 ×1.5 → **×1.6** | 让血量倍率重新起作用 |
| P2 | `addPack` 稀有卡包出现率 | 公式里的秘藏等级改用 `min(s,10)` | 防止深渊里稀有度无限膨胀 |
| P2 | 黑金之约 | 改成「SSR 概率 +x%」，同时删掉 `PITY=40` | 第 3 章以后保底就没用了 |
| P2 | `bossHp` | 重试时单发伤害取 max(首次, 当前)×0.8 | 防止故意弱配装压血 |

改完以后建议重跑 `sim2.cjs`（routes 和 ratchet 两个实验），再跑 `/balance-check`。
